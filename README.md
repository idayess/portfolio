# Портфолио Ida Yess

Автономная адаптивная страница на HTML, CSS и JavaScript. Секции, тексты и сетки свёрстаны нативно; PNG используются только для фотографии и отдельных экранов интерфейса.

## Просмотр

Откройте `index.html` в браузере или запустите локальный статический сервер из этой папки.

## Перед публикацией в Tilda

1. Загрузите файлы из папки `assets` в медиатеку Tilda и замените локальные пути на полученные адреса.
2. Подставьте реальные ссылки в кнопки `CV` и `Telegram` вместо `href="#"`.
3. Код можно разместить в блоке T123 либо подключить как отдельную страницу/внешний файл.
